## 🎨 How to Use ChromaMerge

Using ChromaMerge is straightforward. Here’s how to group and merge your color codes:

1. **Add Color Codes:** 
   - Click on the "Add Color" button to input your color codes. You can enter colors in various formats (e.g., HEX, RGB).
2. **Select Grouping Method:** 
   - Choose the grouping method based on CIEDE2000 color difference. This helps you find colors that are close to each other.
3. **Merge Colors:** 
   - After grouping, you can merge similar colors into a single color to simplify your color palette.
4. **Export Results:** 
   - Click on the "Export" button to save your merged color codes back to a new CSS file.

## 🔧 Troubleshooting

If you encounter issues while using ChromaMerge:

- **Application Won’t Open:** Ensure that you have the correct .NET version installed. Restart your computer and try again.
- **Colors Not Grouping:** Check your input format. Make sure you enter valid CSS color codes.
